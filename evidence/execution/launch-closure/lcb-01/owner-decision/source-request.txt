# 3. 当前 LCB-01 已确认事实

以下内容已具有充分调查证据，除非执行时发现直接相反的新证据，否则不得重新从零研究。

## 3.1 Full View Factor Reference defect

Frozen Reference：

```text
pvlib/solarfactors v1.6.1
commit ecbfc863657e239817603a43898ae173c7ccad9c
```

Full VF 已确认存在真实 implementation defect。

核心问题：

> `_vf_hottel_gnd_surf()` 的带符号 crossed / uncrossed Hottel 表达式隐含依赖 endpoint high/low ordering；水平或近水平子段经过 binary64 rounding / cutting 后发生 equal-height tie 或 ordering reversal 时，Reference 可产生错误负 View Factor。

已确认：

- Geometry 坐标正确；
- Surface identity 正确；
- front/back identity 正确；
- Approved Geometry Golden 正确；
- 不需要修改 P3 Geometry。

不得通过以下方式修复：

```text
abs(final_matrix)
clamp(F, 0, 1)
tilt > 90° folding
front/back swap
Geometry endpoint reordering to fit Reference
```

## OD-LCB01-03 — VF physical contract

批准统一物理原则：

View Factor 必须以：

```text
semantic surface identity / outward normal
+
physical line-of-sight visibility
+
non-negative geometric exchange
```

定义。

Hottel：

> 是 analytic realization，不是 physical semantics。

Endpoint ordering：

> 只允许作为局部计算构造，不得定义 surface identity、visibility 或物理符号。

---

## OD-LCB01-04 — Primary invariant

批准一级 invariant：

```text
0 <= F_ij <= 1
```

对适用 active physical / residual entries执行。

Reciprocity 和 closure：

> 仍然必须验证，但不是合法性的充分条件。

必须保留 mutation tests：

- negative but reciprocal；
- closure-pass but invalid-entry；
- `F > 1`；
- 其他现有非法 matrix mutation。

---

## OD-LCB01-05 — prohibited repairs

正式禁止：

```text
global matrix abs
clamp invalid F
fold tilt > 90°
swap front/back
change Geometry to reproduce Reference
relax tolerance to absorb nonphysical Reference values
```

---

## OD-LCB01-06 — Fast geometric policy

批准以下物理政策：

> Fast ground / PV geometric groups 应基于同一 finite physical exchange 进行聚合，而不是依赖越出 finite domain、endpoint reversal 或 catastrophic cancellation 的 Reference proxy。

多个 receiver segment：

> 应按长度聚合同一物理交换，或使用可证明等价的直接 group computation。

但必须保留：

```text
Fast irradiance / Fast simulation
```

仍是独立近似模型。

本决定：

- 不自动关闭 CDR-007；
- 不声明 Fast == Full；
- 不批准全部 Fast simulation semantics；
- 不允许 Adaptive Planner 改变 underlying physical geometry。
