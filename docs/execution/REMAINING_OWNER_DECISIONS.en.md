## OD-01 — IntervalDifference residual semantics

P3 §5.4 calls Interval finite and closed, permits a point interval, and exposes IntervalDifference; CDR-006 calls subtraction normative but only complete coverage is approved in Golden. Strict [0,2]\[1,2]=[0,1) cannot be represented by closed intervals. Endpoint membership is observable through contains/intersection even though it has zero measure. This is BF-01, a public contract ambiguity, not a private implementation choice.
Recommended: define IntervalDifference as the ordered closures of positive-length connected components of the residual, after subtracting positive-length overlap. It is a residual-span operation, not strict set difference. No overlap or endpoint-only/point subtraction leaves a positive-length minuend unchanged; full coverage yields empty; a point minuend yields empty. Do not apply active-length/snap predicates inside math: every mathematically positive span is returned and Geometry separately classifies it. Examples: [0,2] minus [1,2] -> [0,1]; minus [0.5,1.5] -> [0,0.5],[1.5,2]; minus [1,1] -> [0,2]; [1,1] minus any interval -> empty. Membership at a cut belongs to both closed span representations; boundary ownership and touch classification must use the separate intersection/predicate contract, never infer a shaded area from endpoint duplication.
Alternative: introduce open/closed endpoint flags and strict set difference, including point remnants; this changes the approved public value/result model and adds complexity with no current positive-area consumer. Recommendation preserves the existing closed Interval type and lengths, but requires a signed additive P3/CDR-006 semantic clarification. The old approved document stays byte-identical. New analytic endpoint/point/partial-cover fixtures are a separately approved supplement; do not refresh geometry-golden-v0.1.
Owner response: approve the complete residual-span definition and additive clarification, or choose strict endpoint topology. Validation: analytic table, complement length, no positive overlap, reversed bounds rejected, touch-only zero shading. Affects math/geometry public API, not existing 55-case numeric tolerance.

## OD-03 — CDR-002 hemisphere without recursion

CDR-002 / DEV-001; affects AOI, Perez and source hemisphere. Reference reverses orientation recursively; issue6 probe reaches RecursionError. Independent identity: reversing a normal negates the dot product, so recursion is unnecessary.
Recommended: compute one clipped mu, classify front if mu>delta, back if mu<-delta, grazing otherwise, delta=64*f64::EPSILON (dimensionless); use one signed value for both sides. This proposed roundoff band is separate from geometry orientation and acceptance tolerance and needs independent high-precision trig boundary evidence before approval. At grazing direct/circumsolar projection is zero on both sides; isotropic/horizon remain. Evaluate Perez coefficient strengths algebraically without dividing POA by a zero geometric factor; DHI=0,DNI>0 has zero diffuse/circumsolar/horizon, a named direct-only limit. No recursion, no sign inference from rounded acos. The finite band deliberately changes near-grazing output and must be named in the CDR.
Alternative: exact sign mu classification, no band, still one-pass. It avoids a new band but exposes platform sign noise at orthogonality. Recommend the bounded, independently tested band. Raw issue6 failure stays; corrected tests cover exact orthogonality, +/-delta and adjacent f64 values, normal reversal, DHI=0 and finite bounded outputs. Owner must approve the numeric band with evidence, not infer approval from this recommendation. API exposes grazing status in trace; no new runtime dependency.

## OD-04 — CDR-004 incident solve and absorption

CDR-004 / DEV-008,009,010; affects F/G, optics, radiosity and qabs. Reference inverse-rho fails at zero, custom AOI mutates F and omits ground absorption. Independent derivation: qinc=E+F R qinc; after removing known sky, (I-Fpp Rp)qinc=E+Fps Lsky. q0=R qinc; zero rho follows continuously. Ground absorbs (1-albedo) of incident radiation.
Recommend incident-form partial-pivot LU through a native backend adapter; no explicit inverse, regularization or least-squares fallback. F/G separate allocations or immutable independent views; Gground=(1-albedo)Fground even with custom PV AOI. No-custom-AOI Eabs=(1-rho)E, G=(1-rho_receiver)F. Custom curves are absolute absorption modifiers, with separately configured uniform rho; do not assert qabs=(1-rho)qinc for arbitrary curves. Do assert the source-plus-G formula and constant-ground identity. Preserve ReferenceMidpoint300 whole-bin approximation, without G<=F clipping.
Accept finite rho/albedo in [0,1], including 0/1; singularity is a system result. Residual is computed against original B,b; denominator 0 and residual 0 means eta=0. Condition estimate required in acceptance traces; high-condition systems must either meet an approved condition-aware forward budget or return NumericalFailure, never success based only on small residual. Exact residual/condition thresholds are OD-08 approved evidence, not guessed backend defaults.
Alternative: preserve reference defects under a reference-only profile; not recommended for product. Golden requires raw F captured before AOI, analytic 1x1/2x2 systems, zero-rho limit, custom-ground absorption and singular/near-singular cases. Owner approves equations, absorption separation and diagnostic failure policy. Backend/version/layout remain implementation choices after license/MSRV/features evaluation.

## OD-05 — CDR-005 named Perez corrections

CDR-005 / DEV-005,012,019,022,024 is not one binary fix. Recommend three explicit choices: (a) correct the missing front horizon obstruction using a signed, receiver-facing angular construction on both sides; (b) retain abs(P_horizon) and the reference back circumsolar cos(z) divisor for 0<=z<90 as named HybridPerezReference approximations; (c) preserve finite signed empirical components, report NegativeEmpiricalComponent, never blanket-clip F1/sky/components to positivity. Full nonnegative-energy invariants apply only when source/kernel assumptions hold. z>=90 is handled by OD-02, and nonfinite overflow returns NumericalFailure.
For (a), from each receiving surface centroid consider the adjacent row in that side's facing horizontal direction; no neighbor means h=0. Horizon elevation theta=max(0,atan2(y_neighbor_top-y_centroid,abs(dx))) in degrees; use atan2 at dx=0. h=min(1,theta/band), band finite in (0,90], default 6.5 degrees. Apply H=abs(P_horizon)*(1-h) to that receiving side's lit and shaded surfaces. A horizontal-normal tie has zero horizon projected source at exact flat/180; define h=0 there. This is a proposed angular-band model, not a claim that a paper mandates the approximation. Needs independently constructed occlusion fixtures, front/back orientation checks through tilt 90/120/180, and same-geometry mirror checks where model symmetry applies. No use of an unmerged upstream PR as approved truth.
Alternatives: keep front omission (reject); impose symmetric cos85 floor / signed horizon now (new model revision with broader validation). Recommend minimum explicit correction plus named historical approximations to limit unvalidated physics changes. Perez 1990 equation (9) permits signed F2, while pvlib uses cos85; these are evidence of distinct choices, not proof of empirical accuracy. Anoma/Marion full-text gap remains; independently derived angular tests can support this chosen software contract, not broad scientific validation. Owner must approve (a)-(c) individually, model_revision and corrected front cases; tolerance must not absorb model changes.

## OD-06 — CDR-007 Fast transmission

CDR-007 / DEV-015 affects Isotropic Fast environment front-shaded irradiance. Reference Pps=Piso-Dfront omits transmitted direct light, while Hybrid restores tau terms. Recommend Pps=Piso-(1-tau)*Dfront. Independent limits: tau=0 matches reference, tau=1 restores Piso; derivative with respect to tau is Dfront. Expected target increment is rho_front*F_target,front_shaded*tau*Dfront >=0 in the valid nonnegative domain. Keep the documented isotropic transposition for Piso in both Fast model families; do not replace it with Perez based on the variable name. Full remains a different multiple-reflection model.
Alternative: preserve a named legacy Fast approximation; recommendation fixes the isolated inconsistency and versions the deviation. Raw remains unchanged; corrected cases cover tau=0/0.5/1, rho=0, no neighbor, no shade, selected edge/middle row and segment. Owner approves the formula, fields and migration note. API availability remains CAP13/CAP15; numeric difference is model correction, not tolerance.
